这些篇目被引用得最多，也最容易被断章取义。每篇导读只做四件事：

1. 说明**写作背景**——什么问题促成了这篇文章；
2. 拆出**核心论点**——作者实际主张了什么；
3. 摘出**关键表述**——需要回到原文核对的句子；
4. 给出**阅读提示**——最容易读偏的地方在哪里。

导读文字是本站撰写的概述，不是原文。引用与理解请回到人民出版社第二版正文。
